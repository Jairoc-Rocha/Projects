# Kitchen Lab — Identidade Visual Final

## Conceito

Kitchen Lab é uma hamburgueria com aparência de laboratório gastronômico: moderna, autoral, urbana e experimental.

A ideia é fugir do visual comum de cardápio online e apresentar uma interface com identidade forte para um projeto final fullstack.

## Slogan

**Experimente. Descubra. Vicie-se.**

```bash
cd front-end-kitchen-lab-final
npm install
npm run dev
```

## Observação

Esta versão mantém a lógica principal do sistema e altera a camada visual do front-end. As chamadas para o backend foram mantidas, como:

- `/login`
- `/register`
- `/me`
- `/logout`
- `/get-products`
- `/create-cart-item`
- `/get-cart-items`
- `/delete-product/:id`
