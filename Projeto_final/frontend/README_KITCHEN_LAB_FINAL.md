# Front-end Kitchen Lab Final

Versão final melhorada do layout Kitchen Lab para o projeto Casa do Hamburger.

## Tecnologias

- React
- Vite
- CSS puro
- React Router
- Lucide React

## Rodar o projeto

```bash
npm install
npm run dev
```

## Importante

Este pacote é apenas o front-end. Para login, produtos e carrinho funcionarem completamente, o backend precisa estar rodando em:

```txt
http://localhost:3000
```
